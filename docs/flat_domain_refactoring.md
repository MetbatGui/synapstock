# 평탄화된 경로 기반 플랫 도메인 모델 리팩토링 기록

- **작업 일시**: 2026-06-15
- **작업 브랜치**: `refactor/flat-domain-model`
- **주요 목표**: `Board`와 `Node` 도메인 모델을 기존의 재귀적 트리 구조에서 절대 경로 기반의 플랫 맵(`dict[path, Node]`) 구조로 리팩토링하여 복잡한 재귀 알고리즘 제거 및 성능 최적화.

---

## 1. 주요 변경 및 아키텍처 아웃라인

### 도메인 모델 (`models.py`)
- `Board` 모델의 자식 노드 중첩 구조를 제거하고, 경로(예: `"theme_data/반도체/IDM"`)를 키로 하는 단일 평탄화 딕셔너리(`nodes: dict[str, Node]`)로 변경.
- `Node` 모델에서 하위 노드 리스트(`nodes`)를 제거하고, `parent_path`와 `depth` 속성을 통해 계층 관계를 관리하도록 단순화.

### 저장소 레이어 (`board_repo.py`)
- 기존에 디스크에 저장되어 있던 구형 재귀 트리 JSON 구조를 플랫 `Board` 모델로 자동 복구 및 파싱하는 호환성 마이그레이션 로직 구현.
- 저장 시에는 신규 규격인 플랫 딕셔너리 구조로 디스크에 안전하게 쓰기 수행.

### 서비스 및 API 마샬링 호환성
- `CommandService`, `QueryService`, `SyncService` 등 핵심 비즈니스 로직 플랫 도메인에 연동.
- API 라우터(`board_routes.py`)에서 응답 시 플랫 모델 데이터를 구형 트리 포맷으로 역직렬화(마샬링)하여 반환함으로써 프론트엔드 코드 수정 최소화 (API 하방 호환성 100% 보장).

### Miro 마인드맵 어댑터 (`miro_mindmap.py`)
- Miro 보드 싱크/로드 시 사용되는 계층별 좌표 계산 및 커넥터 연결 연산 로직을 플랫 모델에 맞게 평탄화하여 재작성.
